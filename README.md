# Bingtellar Onboarding App

This is the **Bingtellar Onboarding React web application**, built with **React**, **Vite**, and **Tailwind CSS**.  
It includes features like **dark/light mode**, responsive design, and modern UI components for a smooth onboarding experience.

## Features

- Responsive layout for **mobile and desktop**
- **Dark and light mode** toggle
- Built with **React + Vite** for fast development and HMR
- Styled using **Tailwind CSS**
- Easily extensible for future features

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/isaiah-david/bingtellar-onboarding-app.git
Install dependencies:

npm install


Run the development server:

npm run dev


Open your browser at http://localhost:5173 to see the app.

Deployment

Build the project for production:

npm run build


Deploy the contents of the dist folder to your preferred hosting provider.
